# Learning Kubernetes

Notes and hands-on practice for Kubernetes, kept in one place. Two tracks, read in either order.

| Track | What it covers | Start here |
|---|---|---|
| [KRM](./krm/) | Building platform APIs on Kubernetes - CRDs and controllers, Crossplane, kro. Write YAML, apply to minikube, iterate. | [KRM index](./krm/README.md) |
| [CKAD](./ckad/) | Notes from the Certified Kubernetes Application Developer program - deploying, configuring and troubleshooting apps on a multi-node cluster. | [CKAD notes](./ckad/index.md) |

KRM is active; CKAD is a finished set of notes from passing the exam.
